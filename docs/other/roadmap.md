# 后续开发规划

我们会持续跟进Unity的新版本，并不断优化解释器的执行性能、内存占用和元数据加载速度。

## 持续进行的工作

- 跟进Unity新发布的LTS版本，及时合并最新的il2cpp代码到il2cpp_plus仓库
- 继续优化解释器执行性能
- 继续降低元数据的内存占用与加载耗时
- 修复社区反馈的问题

## 已完成的重要特性

- 完全泛型共享（商业版）
- 差分混合执行 DHE（商业版）
- 热重载，支持100%卸载程序集（商业版）
- dll加密与访问策略（商业版）
- 鸿蒙平台、团结引擎支持
