# 免费试用

HybridCLR 热重载版免费试用基于 **HybridCLR 9.0.0**。

## 支持范围

- Unity 版本为 **2022.3.62f3**、**6000.0.80f1** 或 **6000.3.22f1**。请选择与你的 Editor 版本对应的试用包。
- Unity Editor 可运行于 **Windows 或 macOS**。
- 试用包按平台单独提供。**Android 包**仅支持 ARM64（arm64-v8a），**iOS 包**仅支持 ARM64 真机（Device SDK）。请按目标平台选择试用包。
- 在 Player Settings 中关闭 **增量式 GC（Use Incremental GC）**。
- 仅支持 **Release** 构建。关闭 **Development Build** 及其相关选项，包括 **Profiler（Autoconnect Profiler、Deep Profiling）**和 **Script Debugging**。
- 试用版不包含代码加固功能。

## 试用规则

- 只面向企业用户
- 可免费反复试用。如需技术支持，需要额外付费。
- Player 单次运行的随机试用时限为 **10～15 分钟**。到期后，部分热更新功能将停止工作。试用包仅供评估。
