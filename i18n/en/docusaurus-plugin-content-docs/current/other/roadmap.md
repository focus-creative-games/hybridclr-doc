# Future Development Roadmap

We keep up with new Unity releases and continuously improve interpreter execution performance, memory footprint, and metadata loading speed.

## Ongoing work

- Track newly released Unity LTS versions and merge the latest il2cpp code into the il2cpp_plus repository in a timely manner
- Continue optimizing interpreter execution performance
- Continue reducing metadata memory usage and loading time
- Fix issues reported by the community

## Major features already delivered

- Full generic sharing (commercial editions)
- Differential Hybrid Execution, DHE (commercial editions)
- Hot reload with 100% assembly unloading (commercial editions)
- DLL encryption and access policies (commercial editions)
- HarmonyOS and Tuanjie Engine support

If you need a particular feature, or would like us to prioritize something, let us know via [Contact Us](./contactme.md).

:::
