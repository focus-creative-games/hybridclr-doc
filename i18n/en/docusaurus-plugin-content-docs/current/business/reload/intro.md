# Introduction

The Hot Reload Special Edition provides support for the unique `Hot Reload Technology`. It can completely unload or reload an assembly at runtime, especially suitable for mini-game collection type games.

## Advantages

- Includes all features of the [Professional Edition](../pro/intro.md)
- Supports [Hot Reload Technology](./hotreloadassembly.md)
- Supports [Access Control Mechanism](../accesspolicy.md), **limiting the set of functions that can be accessed within hot update assemblies**. Suitable for creating sandbox environments in UGC games to prevent malicious player code from causing damage.
- Includes two years of technical support

## Supported Versions

Supports all currently supported Unity LTS versions (2022.3.x, 2023.2.x, 6000.x.y).
